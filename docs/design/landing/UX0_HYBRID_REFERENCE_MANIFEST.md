Rights reviewed through actual primary file descriptions and official Creative Commons deeds, not a search thumbnail's availability.
Downloaded originals match each source page's published SHA-1. The coast page records a Flickr license review.
Creator descriptions identify Batumi; the Chief inspected both downloaded images, but no independent field verification occurred.
Photos are used for private concept review. Publication would still require context-specific publisher/privacy/third-party rights review;
licenses do not warrant every incidental right. No supplier/photographer endorsement is asserted.
An optional Europe Square download returned HTTP 429 and was not used or represented as an acquired asset.

Original photo bytes are unchanged; drawing frames crop and resize copies during export. No recoloring, compositing with fictional structures,
generated extension or AI photo was introduced. Footer credits, photo captions and this manifest travel with the artboards.
Borrow: real light, shoreline texture, quiet composition and sense of place. Do not copy unrelated product layouts,
proprietary interface assets, competitor branding, photos without their license, testimonials or marks.

All map-shaped panels are Chief-authored **nonfunctional map placeholders**, rendered with existing Pillow drawing tools.
They have no geographic geometry, coordinates, provider tiles, route, entrance, live marker or claimed Batumi accuracy.
Visible labels survive the exported mobile/desktop artwork. These are conceptual layout surfaces, not provider render evidence.

Installed Segoe UI is the principal font. Georgia is a restrained H1 editorial heading accent;
both stay within the same palette/spacing system. Installed font files are not redistributed.
Georgian glyph presence was checked locally using fontTools: Segoe UI regular/bold pass the tested string;
Georgia does not. Its optional H1 heading accent is English-only and needs a verified Georgian fallback.
The reference board's Segoe UI font specimen is not an approved translation.
Shaping/native-speaker acceptance, launch languages and webfont licensing remain future checks.

Accessibility reference: [W3C contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
Borrow measurable readability principles; do not imply WCAG conformance of a static drawing.
No competitor screenshot or proprietary template is copied. Original wordmark treatment is a design proposal, not a registered mark claim.
