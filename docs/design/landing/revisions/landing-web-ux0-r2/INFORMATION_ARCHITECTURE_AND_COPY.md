# Small website information architecture and proposed copy

LANDING-WEB only. Home / For Partners / Contact; footer Privacy / Terms / Affiliate Disclosure.
Vision is a Home section, not another large marketing site. Contact/policy destinations are pending real Founder inputs and legal/content review.
The website seeks a credible public presence for affiliate applications and local participation after separate publication approval;
this is a Founder objective, not a proven provider acceptance requirement.

Home: developing context-aware city intelligence → authentic Batumi context → representative visitor need → essential constraint
→ evidence and unknowns → conditional comparison → permitted/future action → future governed agent access → partner invitation.
Existing internal components, first tourist use case in development and future infrastructure are explicitly distinct.

Shared illustrative input: **An outdoor afternoon in Batumi. Step-free access is essential.**
This is an example visitor requirement, not a place/access/availability claim.
Hard-constraint boundary: **Access evidence missing → hold. No defensible option yet. Clarify or wait for evidence.**
Comparison: A/B are conceptual slots, shown only after required checks. The eventual default is up to five eligible alternatives or fewer/none;
no named venue, current eligible inventory, fact, score or superiority is invented.
Action: permitted contact/request → partner response, future and permission-dependent. Request is not booking confirmation or fulfillment.
Agent endpoint: future authorized interfaces; no public API or MCP transport is available by implication.

Headlines are candidate copy, not approved public content:

- S1: “A city is more than a list of places.”
- S2: “The city. The question. The evidence between them.”
- S3: “How a city decision takes shape.”
- Positioning: “Developing context-aware city intelligence, beginning with tourist decisions in Batumi.”
- Concept CTA: “Explore the concept”; business navigation: “For Partners”; deeper invitation: “Explore partner paths”.

The “conversational” element is a representative visitor statement and progressively explained response logic.
It is not a chatbot, working form, recommendation feed or PRODUCT-APP interaction specification.
Contact remains a proposed verified channel, no invented email/address or enquiry success screen.
Privacy/Terms/Affiliate Disclosure are proposed information destinations, not completed legal instruments.
