## Process reconciliation

AEOS v1.2 mandatory delivery stages coexist with the old task lifecycle; readiness is insufficient permission.
G0–G8 are aggregate release criteria, not execution approvals. UX-0–4 are distinct from journey segments 0–7.
Every UX checkpoint requires actual visual evidence and Founder approval before its successor.
Stage 1B needs closure or explicit risk waiver before map visual-style sign-off.
Source rollout proposals (4–6 tickets) and backlog dates do not dispatch work; existing three-ticket limit remains.
New ideas use CR intake and scope/time/risk/contract review before implementation.
Chief controls shared interfaces and sequential path leases; specialists cannot redefine product intent.
Independent QA precedes Founder review. No native role settings, experimental features or tools changed.
