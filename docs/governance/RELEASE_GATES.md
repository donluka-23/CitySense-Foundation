Partner/action gate is OPTIONAL and separate: identity/authority, permissioned publication/contact, current prices/slots,
terms/cancel/support, consent, truthful status and idempotency/confirmation evidence. Failure does not justify simulation.
Payments require authorized provider plus topology/legal decisions; no gate is approved by supplier names.
External API/MCP release additionally requires identity/tenant/dataset scopes, redistribution, shared quotas/TLS,
revocation/audit and independent security/contract tests. Internal schemas do not pass that gate.

Stop/no-go: unsupported required safety/access evidence, rights denial, missing privacy/placement permission,
privileged browser key, stale selected context, unconfirmed transaction presented confirmed, missing independent/human review.
Raise exact blockers and narrower options to Founder; do not silently loosen constraints to meet November.

At each gate record owner, approval, contract/build revision, actual commands/environment/time, screenshots/rights,
limitations, rollback and human acceptance. Historical tests remain historical.
