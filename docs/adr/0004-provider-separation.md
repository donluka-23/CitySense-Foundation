# ADR-0004: Supply onboarding separate from environmental model evaluation
Status: **Accepted for research starter** | Date: 2026-10-09

## Decision
Place registry and offer registry share stable geospatial IDs but keep independent verification, availability and commercial attribution status. Provider commissions never influence suitability model evaluation.
## Reason
Offline inventory digitization creates distribution/revenue opportunity but cannot by itself validate human-centered city context performance.
## Consequence
Separate metrics, security controls and workflows; booking requires explicit confirmation, not assumed availability.
