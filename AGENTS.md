# CitySense Lab: session guide

Act in the role assigned by the current user. A Chief session coordinates bounded work and integration.
Repository documentation and implementation are primary evidence; recover history before alternatives.
Start with [governance index](docs/governance/README.md), then STATUS, charter and relevant contracts.

## Authority and scope
- Current user instructions set session scope. The bootstrap authorizes governance/configuration only.
- Current approved sources: docs/product/CITYSENSE_PRODUCT_BLUEPRINT_v0_4.md and
  docs/governance/CITYSENSE_AGENTIC_ENGINEERING_OPERATING_SYSTEM_v1_2.md; old SOURCES copies stay unchanged.
- Read [versions](docs/governance/VERSION_REGISTER.md); source headers retain old version labels.
- DECIDED clauses establish direction; PROPOSED, TO VERIFY, TO VALIDATE and DEFERRED retain their meanings.
- Existing ADRs, executable schemas, frozen B0 and protected research protocols remain binding in their domains.
- Consult [precedence and decisions](docs/governance/DECISION_REGISTER.md) and [conflicts](docs/governance/RECONCILIATION.md).
- A conflict blocks the affected contract change until explicit founder approval recorded in a CR/ADR.
- Governance and backlog entries do not authorize implementation or prove capability.

## Product invariants
- November 2026 target: closed supervised Batumi tourist pilot; QR mobile web, no mandatory install.
- Thirty Orbi City A Block apartments are an opportunity; permission, occupancy and participants are unverified.
- Eligibility precedes suitability; unknown required safety/access facts cannot be counted as satisfied.
- Desired default is up to five defensible alternatives; never fabricate a fifth or relax hard constraints.
- Coverage-aware retrieval is required direction; preserve current bounded /v1 search until its extension is approved.
- One backend scorer; no LLM-invented facts. Map/cards/chat/route/actions share request revision and selection.
- Keep verified decision, inferred/self-reported action and provider-confirmed fulfillment separate.
- Scores/weights are unvalidated. Preserve B0, A1/B1 evidence and the protected evaluation protocol.
- Commercial priority stays inactive pending conflict resolution; preserve organic scores/order/hash.
- Booking request is not confirmation; schemas and adapters are not running integrations.
- Batumi only initially. No eSIM activation, driver booking, payments, public agent writes or rollout by implication.
- Source rights, freshness, provenance and uncertainty apply across every client. No remote local_research bypass.

## Ownership and handoff
- Read [Chief workflow](docs/governance/CHIEF_ENGINEER_WORKFLOW.md) and the relevant docs/governance/ROLES/ file.
- Use bounded short-lived subagents for explicitly authorized independent audits or disjoint approved tasks.
- One writer per leased path. Shared models, schemas, migrations and interface semantics require sequential Chief assignment.
- Use [task/handoff template](docs/governance/HANDOFF_TEMPLATE.md); state actual tests and evidence.
- Do not install tools, enable experimental features, contact partners or use credentials without explicit scope.
- Profiles are read-only defaults; portable role instructions apply when native role selection is unavailable.
- Preserve uncommitted user work. Never initialize Git, create worktrees, stage/commit or deploy by assumption.
- Independent QA and required human gates follow integration; implementers cannot accept their own release.
